# 📋 Gestor de Rotinas e Matriz de Prioridades

Aplicativo web leve para gestão de demandas, controlo de atrasos, cálculo de tempo parado e matriz de prioridades (Eisenhower).

## 🚀 Funcionalidades

- **Matriz de Eisenhower:** Divisão em 4 quadrantes (Fazer Agora, Agendar, Delegar, Eliminar).
- **Cálculo de Tempo Parado:** Regista automaticamente o tempo acumulado enquanto a tarefa está no estado "Pausado".
- **Aviso de Demandas Atrasadas:** Identificação visual e contador de tarefas fora do prazo.
- **Alertas de Críticas:** Alertas automáticos para tarefas urgentes que estejam atrasadas.
- **Motivo de Atraso:** Campo para justificar pausas e impedimentos.

## 🛠️ Tecnologias Utilizadas

- HTML5
- [Tailwind CSS](https://tailwindcss.com/)
- JavaScript (Vanilla)
- LocalStorage para persistência de dados no navegador.

## 📦 Como Publicar no GitHub Pages

1. Crie um novo repositório no GitHub.
2. Faça upload do ficheiro `index.html` e do `README.md`.
3. Aceda às **Settings** do repositório.
4. Navegue até à secção **Pages** na barra lateral.
5. Em *Source*, escolha a branch `main` (ou `master`) e clique em **Save**.
6. Aguarde alguns minutos e o seu link estará disponível gratuitamente!
